# Lesson — entry format

Target file: `lessons.md`. One line:

```
- YYYY-MM-DD [skill/domain] Error → Correction → Rule for the future
```

Examples:

```
- 2026-11-05 [sport] Counted gym sessions into running load → gym tracked separately → running load only from running activities
- 2026-11-05 [business-analysis] Skipped non-functional requirements → added → always include an NFR section, even if empty with a justification
```

No sensitive data.
