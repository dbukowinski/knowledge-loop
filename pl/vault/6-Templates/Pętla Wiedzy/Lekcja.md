# Lekcja — format wpisu

Plik docelowy: `8-System/Lekcje Claude.md`. Jedna linijka:

```
- RRRR-MM-DD [skill/domena] Błąd → Poprawka → Reguła na przyszłość
```

Przykłady:

```
- 2026-11-05 [sport] Liczyłem siłownię do obciążenia biegowego → siłownia osobno → obciążenie biegowe tylko z aktywności biegowych
- 2026-11-05 [analiza-ba] Pominąłem wymagania niefunkcjonalne → dodane → zawsze sekcja NFR, nawet pusta z uzasadnieniem
```

Bez danych wrażliwych.
